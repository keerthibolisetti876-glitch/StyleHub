# StyleHub – Fashion E-Commerce Website

## Project Overview

StyleHub is a modern, attractive, and responsive fashion e-commerce website developed as part of my internship project. The website provides users with a simple and visually appealing platform to explore fashion products.

## Features

* Responsive and user-friendly design
* Attractive homepage with a fashion-themed layout
* Fashion product display section
* Navigation menu for easy browsing
* Interactive buttons using JavaScript
* Clean and modern user interface
* Compatible with desktop, tablet, and mobile screens

## Technologies Used

* **HTML5** – Used to create the structure of the website
* **CSS3** – Used for styling, layout, colors, and responsiveness
* **JavaScript** – Used to add interactivity and dynamic functionality
* **Visual Studio Code** – Used for development

## Project Structure

```text
stylehub/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run the Project

1. Download or clone this repository.
2. Open the `stylehub` folder in Visual Studio Code.
3. Open the `index.html` file in a web browser.
4. For a better development experience, use the Live Server extension in Visual Studio Code.
